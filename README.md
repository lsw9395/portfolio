# 이성운 개발자 포트폴리오

Java·Spring 기반 업무시스템 개발과 MES 연계 실무 경험을 소개하는 반응형 정적 사이트입니다.

## 파일
- `index.html`: 소개, 경력, 기술, 교육, 자격·수상
- `app.js`: 프로젝트 내용, 분류 필터, 상세 보기
- `style.css`: 데스크톱·모바일 및 인쇄 레이아웃
- `.nojekyll`: GitHub Pages 정적 파일 제공

## 미리보기
`index.html`을 브라우저로 열면 됩니다. Node.js나 별도 빌드는 필요하지 않습니다.

## GitHub Pages 공개
1. GitHub 계정 `lsw9395`에 공개 저장소 `portfolio`를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 업로드합니다.
3. 저장소 Settings → Pages → Build and deployment에서 Source를 `Deploy from a branch`, Branch를 `main`, 경로를 `/(root)`로 지정하고 저장합니다.
4. GitHub가 배포를 완료한 뒤 표시하는 주소를 확인합니다. 저장소명이 `portfolio`이면 예상 주소는 `https://lsw9395.github.io/portfolio/`입니다.

## 내용 편집
실무 프로젝트는 사용자 제공 경력을 바탕으로 작성했습니다. 회사 소스와 내부 화면, 연락처·주소·생년월일·자격증 번호는 포함하지 않았습니다. 공개 GitHub 저장소는 링크로 연결했습니다. AI 실습은 AI 도구로 구성한 앱에 키를 적용하고 실행을 확인한 범위로 설명했습니다. 경력은 2025년 10월까지의 제공 이력을 기준으로 합니다.

대표 그래픽은 이 포트폴리오를 위해 만든 텍스트 기반 개념 표현이며 실제 회사 화면이 아닙니다. 참고 사이트의 코드·이미지는 복사하지 않았습니다.
